
# 🛠️ Tech Stack

## Frontend:
-  React.js, React Router, React Context
## Backend / Cloud: Firebase
  
## Databases:
- Firebase Realtime Database (for device states & real-time power updates)
- Firestore Database (for user info, monthly power consumption, and structured data)

- Authentication: Firebase Auth
- Charts & UI: Chart.js, Tailwind CSS, Material Icons

## 📖 Overview  

### 🔑 Login & Signup Page  
- Secure user authentication using **Firebase Auth**  
- Allows creating new accounts and logging in existing users  
- Validates input fields for security and usability
